# Stockly

A simple Android app for keeping track of inventories.

- Create as many separate inventories as you like; the start screen lists them all.
- Tap an inventory to see its items. Each item has a name, quantity, price per unit and an optional product link.
- Long-press an item to move it up or down, edit it, or remove it. Long-press an inventory to rename or delete it.
- Sort items by name (A–Z, Z–A), date (newest, oldest) or price (high to low, low to high).

Everything is stored on the phone; no account needed.

## Getting the APK

Every push to `main` runs the **Build APK** workflow. Open the latest run under the Actions tab and download the
`stockly-apk` artifact, unzip it, and install `app-debug.apk` on your phone (allow installs from unknown sources).
